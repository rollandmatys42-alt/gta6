# GTA6 Creator Hub

A GTA VI creator platform for curated video downloads, creator subscriptions, community publishing workflows, marketplace listings and editorial news.

> Independent fan platform. Not affiliated with, endorsed by, or sponsored by Rockstar Games or Take-Two Interactive.

## Development

The application is built with React, TypeScript and Vite, with Base44 providing app hosting and backend services. Secrets and provider credentials must be configured in Base44, never committed to this repository.
